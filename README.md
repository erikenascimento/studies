# studies
This repository is where I stored "follow-along" courses files and templated projects challenges.  
It has little portfolio value, but it is the place where my first steps in the tech field were registered.  
I'll not be updating this repository in the feature with new content. But I'll be transfering files from other study related repositories to here and organizing the repository structure, adding Readme files to every project, things like that.

## What does each folder here means:
The names are pretty much self explanatory, they house everything related to that tech field.  
"Others" is the only exception to that. That folder houses minor stuff that is not related to any of the fields directly like Regex and Webpack.  

## What's inside those folders:
Each folder then separates its subfolders in specific tools.  
For example the Frontend folder contains subfolders like Angular, Bootstrap, React, etc.
Inside each folder you'll also find another Readme file offering further guidance.
